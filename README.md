# Test de réflexes

### ▶ [JOUER MAINTENANT](https://mael71.github.io/Jeu-R-flexe/)

Petit jeu web qui mesure ton temps de réaction, dans le style d'[OmriTweaks](https://github.com/mael71/OmriTweaks-CS-Telechargement).

## Jouer
➡ **Lien direct : https://mael71.github.io/Jeu-R-flexe/**

(Le lien fonctionne une fois **GitHub Pages** activé : Settings → Pages → Branch `main` → `/root`. Sinon, ouvre simplement `index.html` dans un navigateur.)

## Règle
Clique pour lancer. L'écran passe au rouge (« Attends… »), puis au **orange** : clique le plus vite possible. Le temps s'affiche en millisecondes et le meilleur score est gardé en mémoire. Marche à la souris, au doigt ou avec la barre **Espace**.

Moins de 250 ms, c'est du très bon niveau.
